Executive Pitch Matrix for Datathon Judges

1. Why O(1) Mobile Index + Fingerprint Beats 1-to-N:

Searching 1 fingerprint across 1.4 billion citizens (1-to-N) causes high latency and False Acceptance errors. Typing a 10-digit mobile key turns it into an instant O(1) primary key lookup in Db2 (<2ms) followed by a single 1-to-1 enclave hash verification.

2. 100% Phone-Free Across All 3 Tiers:

Customers never need to carry a smartphone, scan damaged QR codes, or worry about dead batteries. Even for Tier 3 high-value purchases (>₹5,000), the 4-digit PIN is entered directly on the merchant's encrypted POS keypad.

3. Zero Raw Biometrics Stored (DPDP & RBI Compliant):

Raw fingerprint images never leave the capacitive sensor. The POS generates a salted SHA-256 HMAC token that is compared inside the tamper-responsive IBM Crypto Express8S HSM enclave.

4. Real-Time Multi-Device State Synchronization:

Every enrollment, balance deduction, and CICS settlement receipt is broadcast in real-time across all active terminals and persisted in the shared ledger.
